# 合规声明

> 适用对象：**曦和 · AI Agent 运行底座（Xihe Agent Runtime）** —— 面向国产算力的多通道 AI Agent 运行底座
> 对应本仓库的**基金申报版**（干净入场、无大二进制、无密钥）。
> 版本：v2.0（2026-10-13 更新）｜前版 v1.0（2026-05-19，比赛期）

---

## 一、核心声明

> 本项目主推理与实证链路为**在国产 GPU（沐曦 MetaX C500）上自部署大模型并自建接入层**，
> **未依赖任何外部云端模型服务作为功能前提**；模型权重全部为开源模型（Qwen 系列，Apache-2.0）。

**本次提交的数据来源口径（已冻结）**：

> **本项目提交的全部调用日志与性能数据，均来自通道③（沐曦 C500 自部署 32B）。**
> **通道① 云端 API 仅作为多源韧性架构的对照项陈述，不用于本次实证数据。**

### 2.2 未依赖外部云端模型服务

- 架构上：Gateway **不含任何外部云端 provider**，全部请求经本机应龙桥接器路由
  （配置模板见 [`../src/config/openclaw.template.json`](../src/config/openclaw.template.json)）。
- 代码上：本仓库源码中**无任何云端 provider 的 API 调用实现**；
  `api_key` 字样仅出现在**占位符形态**（`${MUXI_API_KEY}` / `your_..._here`）。
- 数据上：**本次提交的全部调用日志与性能数据均取自通道③**（自备国产卡、自部署、自建服务）。
- 通道① 的角色：**多源韧性架构的对照项** —— 只作架构叙述，**不用于实证数据**。

### 2.3 国产算力适配的真实性

- 在 C500 上完成从「开荒 → 验卡 → 拉模型 → 起推理 → 隧道打通 → 桥接接入」的**全链路**；
- 端到端实测通过：`/v1/models` 1.07 s、中文对话 1.91 s、点名通道 4.16 s、复杂任务自动路由 19.68 s；
- 通道③ 升级为**可调用工具**（`--enable-auto-tool-choice --tool-call-parser hermes`），
  实测返回 `finish_reason = tool_calls`；
- 32K 上下文有**显存账**支撑（32K 需 8.44 GiB KV cache，实测占用 29516/32000 MiB）——
  **不是模型上限，而是显存上限**，这一结论已写入技术材料。

### 2.5 数据与隐私

- 会话与调用日志默认落在**本机运行期目录**（`XIHE_RUNTIME_ROOT`，默认 `<repo>/.runtime`），**不入库**；
- 公开前对全仓做**敏感信息全量扫描**（[`../scripts/scan_secrets.py`](../scripts/scan_secrets.py)）：
  真实密钥 / 网关 IP / SSH 用户名 / `password` / 本机绝对路径 —— **均 0 命中**；
- 截图证据：**主动剔除 1 张含私钥画面的截图**（该画面含 `id_ed25519` 全文）；
- 日志中的人名与绝对路径按**匿名化**处理（隐私项，非安全漏洞项）；
- 双账号隔离：AI 组件运行在**受限标准用户**下，无法接触管理员权限；服务仅 bind 回环。

## 四、诚实的局限（主动说明，不待评审发现）

1. **冷启动**：社区侧 star / fork / 贡献者当前为 0；定位为**从生产自用走向社区共建**。
   已建立的是**可被第三方核验的工程痕迹**（提交历史、Issue 记录、压测原始数据、23 张截图），而不是数字。
2. **来源追溯缺口**：09-21 与 10-11 两次余额读数区间消耗 **122.61 元 ≈ 49.04 h 机时**，
   而报告的「当前实例机时 20h29m」只折 **51.21 元** ⇒ 差 **71.40 元 ≈ 28.56 h**，**原因未验证**。
   ⇒ 若材料同时出现「花费」与「运行时长」，**必须注明口径**（券消费总额 vs 当前实例机时）。
3. **未闭合的验证项**：真实断网 + 长上下文端到端演练未做；`c500_watchdog` 未在真实任务期实跑过
   （仅单测 + 模拟）；09-21 归档内 `max_model_len` 有 16384 / 32768 两处不一致（原因未核实）。
4. **看护层形态**：本仓库的看护层是**按生产参数重写的自包含版本**（生产脚本依赖未随包发布的内部模块）。
   差异逐条列在 [09_初稿与生产的差异声明.md](09_初稿与生产的差异声明.md)。
5. **座舱音频监控**：**内存达标（约 154 MB，验收线 ≤200 MB），CPU 约 17.5%（未达 ≤5% 验收线）** ——
   如实登记，并附后续优化计划（见 [09_初稿与生产的差异声明.md](09_初稿与生产的差异声明.md)）。
