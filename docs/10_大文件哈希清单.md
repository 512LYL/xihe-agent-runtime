# 大文件清单（不入库资产的哈希引用）

> **为什么有这份文件**：本仓库红线是**单文件 > 10 MB 即不入库**（平台硬红线为 > 100 MB 单文件拒收）。
> 但有几件资产体积超标、又必须可被评审**核验其存在与一致性** —— 正确处置不是塞进 Git 历史
> （那正是旧仓 702.6 MB 的根因），而是**留哈希 + 留链接 + 按需提供**。
>
> 下面每个哈希都是 **SHA-256**，由本机 `Get-FileHash -Algorithm SHA256` 实测得到
> （2026-10-13）。任何人拿到同名文件都可自行复算比对，**确认与提交时是同一份**。

## 四、复算方法（自证）

```powershell
# 单个文件
Get-FileHash -LiteralPath "<文件路径>" -Algorithm SHA256 | Format-List

# 一次性核对本文件里列出的所有资产（把路径按需替换）
$files = @(
  "<PPT 原件路径>",
  "<演示视频路径>"
)
$files | ForEach-Object { "{0}  {1}" -f (Get-FileHash -LiteralPath $_ -Algorithm SHA256).Hash, $_ }
```

```bash
# Linux / macOS
sha256sum "<文件路径>"
```
